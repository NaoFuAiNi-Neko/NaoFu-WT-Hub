## 中文

### 这是什么？

NaoFu WT Hub 是面向《战争雷霆》的 **Windows 本地工具**：

- 自定义游戏字体（写入 `fonts.vromfs.bin`）
- 自定义 UI 图标包一键部署（甘城 x 猫羽雫 含视差背景图 + 头像，以及赤风的灰烬战线主题包）
- 自定义游戏内文本（lang，含灰烬战线风格包）
- 自定义语音（陆战、无线电、空战）
- 自定义启动图（图标包在上，启动卡片在下。赤风系列可以下载）
- 支持签名自动更新

### 功能一览

1. **自定义字体** — 选字体 / 系统自带字体 → 生成并导入游戏  
2. **自定义 UI** — 甘城 x 猫羽雫是图标、视差背景图 + 头像、载具卡片。赤风的灰烬战线主题包是图标和载具卡片。两组可以拼着选  
3. **自定义文本** — 下载 RWR / 蓝莓、Sparatoria_Fate 的局部补丁，以及赤风的灰烬战线风格包，写入游戏 lang  
4. **自定义语音** — 陆战、无线电、空战分开做，也可以下载甘城和赤风的语音  
5. **自定义启动图** — 图标包在上，启动卡片在下。赤风系列可以下载。自制启动卡在 800×450 的框里自己缩  
6. **在线公告 & 更新** — 验签清单，安全升级到新版本

## English

### What is this?

**NaoFu WT Hub** is a **Windows local client** for War Thunder:

- Custom in-game fonts
- Custom UI icon packs (Nachoneko, including the parallax background plus avatars, and WindRF’s 灰烬战线主题包 for ASH ARMS)
- Custom in-game text (lang, including the ASH ARMS style pack)
- Custom voice (ground, radio, and air)
- Custom splash screens (icon packs on top, splash cards below; the WindRF series can be downloaded)
- Signed auto-update

### Features

1. **Custom Font** — pick a font or built-in fonts → build & import  
2. **Custom UI** — Nachoneko keeps icons, the parallax background plus avatars, and vehicle cards. WindRF’s 灰烬战线主题包 (ASH ARMS) has icons and vehicle cards. The two can be mixed  
3. **Custom Text** — download RWR, Blueberry, Sparatoria_Fate's patch, and WindRF’s ASH ARMS style pack, then write game lang files  
4. **Custom Voice** — ground, radio, and air are separate; Nachoneko and WindRF packs can be downloaded  
5. **Splash screens** — icon packs sit on top, splash cards underneath. The WindRF series can be downloaded. Homemade cards stay in an 800×450 frame  
6. **Notice & Update** — signed manifests for safe upgrades
