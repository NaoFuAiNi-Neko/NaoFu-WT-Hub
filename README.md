## 中文

### 这是什么？

NaoFu WT Hub 是面向《战争雷霆》的 **Windows 本地工具**：

- 自定义游戏字体（写入 `fonts.vromfs.bin`）
- 自定义 UI 图标包一键部署
- 支持签名自动更新

### 功能一览

1. **自定义字体** — 选字体 / 系统自带字体 → 生成并导入游戏  
2. **自定义 UI** — atlases / images / tex 图标包下载与部署  
3. **在线公告 & 更新** — 验签清单，安全升级到新版本  

### 社区

- QQ 群：`941587776`

- macOS 版仍在施工。  
- 本镜像仓 **不提供源码、不接受 PR**；问题反馈请走官网 / QQ 群 / B 站。

**NaoFu WT Hub** is a **Windows local client** for War Thunder:
